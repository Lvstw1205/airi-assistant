# Shareable Markdown configuration

The runtime reads `config/assistant-core.md`, `soul.md`, `identity.md` and role prompts in
`prompts/agents/`. They contain generic reusable instructions and no owner profile.
The independently downloadable [AIRI Playbook](https://github.com/Lvstw1205/airi-playbook)
adds privacy, permissions, memory, research and operational templates.

Customize your private installation deliberately. Instructions cannot substitute for
application authorization checks. Do not commit private memory or filled user profiles.
