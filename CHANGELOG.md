# Changelog

## 0.2.1 — 2026-10-07

Add a real UI screenshot, architecture diagram and API/MCP code walkthrough. Explain the sanitized public import. Format and annotate the agent runtime without changing its runtime AST; add approval-boundary regression coverage.

## 0.2.0 — 2026-10-07

Single-computer defaults with optional paired workers, a device-add form and automatic
inference-main selection. TLS certificate pinning, signed requests, model-digest matching
and failure cooldown protect routing. Removes the fixed two-Mac layout.
Makes scalar-accounting tests independent of SQLite VM implementation details.

## 0.1.0 — 2026-10-07

First independent community source release. Adds a dedicated launcher, isolated state,
professional documentation, noncommercial license and sanitized configuration defaults.
Private accounts, runtime records and custom personal assets are excluded.
