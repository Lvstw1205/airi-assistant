API

연결한 서비스를 한눈에 관리하세요.

WeatherAPI와 OpenAI는 주소·인증·요청 형식을 자동으로 설정합니다. OpenAI를 대화 모델로 선택하면 대화와 관련 자료가 해당 API로 전송되며 API 요금이 적용됩니다.

문자열 안의 {{task}}는 예약 작업의 지시 내용으로 바뀝니다.

켜면 예약 시점에 이 요청이 실행됩니다. 끄면 승인 대기로 남습니다. API 키는 이 Mac의 사용자 전용 파일에 보관합니다.
